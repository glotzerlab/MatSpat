# MatSpat
MATerial analysis of SPATially resolved histology images.

A high level Python package for physics-informed analysis of spatially resolved, single cell level histology images.


# Input
The data does not technically have to be cells. The main requirement for this package is
that each "point" should be a point particle with a defined x,y location within a grid. Multiple types
of analysis can be done, such as classification, changepoint detection, etc. 

# Method(will be expanded)
Applying _freud_ , spatial analysis tool used for materials science type analysis of particle simulations
Converting static histology slides into radial sequences from the specified core
Computation of partial correlation coefficients 
Sequence modeling with radial sequences using Hidden Markov Models and more deep learning methods

# Output
Classification, Changepoint Detection, and further analysis of quantile-discretized radial sequences 
from spatially aware data.
